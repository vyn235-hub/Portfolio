05 / Projects

Dự án cá nhân

Ba ý tưởng dự án cá nhân theo định hướng phát triển game, tập trung vào gameplay 2D và thiết kế màn chơi.

Pixel Quest – Game platform 2D

Thiết kế game platform 2D với nhân vật có thể chạy, nhảy, né chướng ngại vật và thu thập vật phẩm. Tập trung vào điều khiển nhân vật, va chạm, tính điểm và bố trí màn chơi.

  • C++
  • SFML
  • Gameplay 2D
  • Collision

Space Defender – Game bắn phi thuyền

Xây dựng game arcade nơi người chơi điều khiển phi thuyền né đạn và tiêu diệt kẻ địch. Tích hợp hệ thống bắn, sinh đợt kẻ địch, tính điểm và tăng độ khó theo thời gian.

  • Python
  • Pygame
  • Game loop
  • Sprite

Dungeon Puzzle – Game giải đố mê cung

Thiết kế game giải đố theo màn, trong đó người chơi khám phá mê cung, thu thập chìa khóa và mở lối đi. Tập trung vào logic tương tác, điều kiện hoàn thành màn chơi và độ khó tăng dần.

  • Python
  • Pygame
  • Game logic
  • Level design
